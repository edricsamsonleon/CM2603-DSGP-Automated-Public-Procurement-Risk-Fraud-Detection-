# CM2603-DSGP-Automated-Public-Procurement-Risk-Fraud-Detection-
End-to-end data engineering and AI decision-support system for Sri Lankan public procurement. Standardizes unstructured tenders into OCDS 1.1, flags anomalies via OCP Cardinal rules, CPV-clustered Isolation Forest, and a market pricing agent, and explains risks using an Open Knowledge &amp; RAG layer.
